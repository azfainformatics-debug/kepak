# KEPAK BATARA - Aplikasi Rewards & Dashboard

Sistem manajemen rewards untuk komunitas petani urban dengan dashboard admin yang lengkap.

## 📱 Aplikasi yang Tersedia

### 1. User App - KEPAK BATARA Rewards (`index.html`)
Aplikasi mobile-friendly untuk pengguna:
- **Login & Authentication** - Sistem login dengan HP/NIK dan PIN
- **Points System** - Kumpulkan points dari berbagai aktivitas
- **Aktivitas Harian** - Check-in, upload foto, catat panen, barter, tutorial
- **Achievement & Badges** - Sistem prestasi dan badge
- **Leaderboard** - Peringkat pengguna berdasarkan points
- **Redeem Rewards** - Tukar points dengan hadiah menarik

### 2. Admin Dashboard (`dashboard.html`)
Dashboard admin untuk monitoring dan manajemen:
- **Dashboard Overview** - Statistik real-time (pengguna, aktivitas, hadiah, points)
- **User Management** - Kelola data pengguna
- **Activity Monitoring** - Pantau aktivitas pengguna
- **Rewards Management** - Kelola hadiah dan stok
- **Analytics & Reports** - Grafik dan visualisasi data lengkap
- **Settings** - Konfigurasi sistem

## 🚀 Cara Menggunakan

### User App
1. Buka `index.html` di browser
2. Login dengan nomor HP/NIK dan PIN (6 digit)
3. Untuk demo, masukkan data apapun - sistem akan auto-register
4. Mulai kumpulkan points dari berbagai aktivitas!

### Admin Dashboard
1. Buka `dashboard.html` di browser
2. Akses langsung ke dashboard admin
3. Navigasi menu sidebar untuk berbagai fitur:
   - 📊 Dashboard - Overview statistik
   - 👥 Pengguna - Kelola user
   - 📋 Aktivitas - Monitor aktivitas
   - 🎁 Hadiah - Kelola rewards
   - 📈 Analytics - Lihat laporan
   - ⚙️ Pengaturan - Konfigurasi
